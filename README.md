# Financella - Personal Finance Tracker
A full‑stack web application for managing personal expenses, built with Node.js, Express, MongoDB, and vanilla JavaScript.

## Overview
Financella allows users to:
- Create an account
- Log in securely
- Add, view, filter, sort, and delete transactions
- View transactions in a list view or calendar view
- Store all data securely in MongoDB
- Authenticate using JWT tokens

## Features
### Authentication
- User signup
- Secure password hashing with bcrypt
- Login with JWT token
- Protected routes using middleware

### Transaction Management
- Add new transactions
- View all transactions
- Delete transactions
- Sort by date or amount
- Filter by category

### Calendar View
- Monthly calendar
- Highlights days with transactions
- Click a date to view daily details

### Frontend
- Vanilla JavaScript
- Responsive layout
- Clean UI with list + calendar
